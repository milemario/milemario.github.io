# Cuckoo's Egg audio upload area

Upload the manually generated ElevenLabs MP3 files into the folders below. Keep the filenames exactly as listed in the narration script so the game can load them later.

```text
assets/audio/scenes/   Main scene narration
assets/audio/choices/  Optional narration for choice results
assets/audio/endings/  Ending narration
assets/audio/music/    Looping background music
```

The browser game will not need an API key once the audio files are bundled here. Do not upload ElevenLabs, OpenAI, Google, or any other provider API keys.

The complete narration text and the same filename list are in the separate `cuckoos-egg-narration-script.md` file prepared for this project.
