A colleague tells you about a security problem. You have three tools to choose from. Pick the best first fit, then see what it can do, what it cannot do, and what you could say next.

How to play

Choose one control for each situation. Some other choices may help too, but the game asks which tool addresses the main issue first. In real incidents, contain immediate harm and involve your security team.
