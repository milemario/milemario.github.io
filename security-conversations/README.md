# Security in Conversation

A browser-based cybersecurity decision game. A colleague describes a realistic workplace security problem, and the player chooses one of three tools as the best first fit.

## Play

Open [Security in Conversation](https://milemario.github.io/security-conversations/).

Choose **Quick chat** for five randomly selected cases or **Full shift** for ten. The game explains each option, gives a practical follow-up line, and reviews the decisions at the end. The tool guide is available during play. Progress is stored only in the browser.

## Tools covered

MFA, DLP, EDR, SIEM, IAM, PAM, email security, vulnerability management, secrets scanning and management, backups and recovery, MDM, WAF, encryption, network segmentation, CASB, VPN, and ZTNA.

## Run or adapt

This is a static HTML/CSS/JavaScript game with no build step or external dependencies. Open \`index.html\` locally, or host this folder on any static web host. Edit the \`scenarios\` and \`toolGuide\` arrays in the script to add or adapt cases.

The game is an educational introduction. Real security decisions depend on context, architecture, incident procedures, and the people who own the systems.
