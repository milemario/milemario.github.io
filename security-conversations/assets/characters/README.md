# Dev SecRPG character portraits

Place the supplied square PNG portraits in this folder with these exact lowercase names:

- `bence.png`
- `mate.png`
- `nora.png`
- `zoli.png`
- `varga.png`
- `kornel.png`
- `klara.png`
- `board.png`
- `regulator.png`

The game reads them from `assets/characters/<name>.png`. Portrait styling is applied in the game; no preprocessing is needed.
